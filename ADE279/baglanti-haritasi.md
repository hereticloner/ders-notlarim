# ADE 279 — Bağlantı Haritası (s. 1–12)

## Temel tez → çıkarımlar

```
Avrupa kültürel bir KONSTRÜKT (Schipperges)
    │
    ├─→ 4 Eckpunkte (Horstmann) — neyin ortak olduğu
    │       │
    │       └─→ çift yönlülük — aynı rekabet hem yenilik hem şiddet
    │
    ├─→ 11 Konstruktionen (Quenzel) — "tanım" denen şeyin 11 farklı hâli
    │       │
    │       └─→ negatif anı topluluğu — suçtan doğan ortak hafıza
    │
    └─→ kimlik kuramı: kişisel / siyasi / kültürel
            │
            ├─→ soğan metaforu (Meyer) — çekirdek yok
            ├─→ faydacı rıza (Nyssen) — en zayıf boyut
            └─→ postnationale kimlik (Habermas) — soy miti yerine siyasi seçim
```

## Didaktik katman (kim bu anlatıyı öğretir)

```
problemorientierter Geschichtsunterricht (Wolf)
    │
    ├─→ 3 aşama: Problemwahrnehmung → Quellenarbeit → Beurteilung
    ├─→ Beutelsbacher Konsens: tartışmalı yargı alınır, ezme yok, tartışma emir değil
    │
    └─→ historischer Vergleich (Horstmann) — ulusal sınırı aşma yöntemi
            │
            └─→ dil kimlik kurucu — yabancı dilde kaynak zorunluluğu
```

## Sınav için üç kanca

1. **Soğan metaforu + faydacı rıza** — "Avrupa kimliğinin en zayıf boyutu hangisi?"
2. **4 Eckpunkte** — sınavın en klasik listeleme sorusu
3. **Negatif anı topluluğu** — dersin "taraf tutmama" ilkesinin kanıtı

## Eksik kalan

- s. 12 sonrası: III. Stationen (Yunan/Roma/Hacılar/Ortaçağ/Erken modern/Aydınlanma) —
  kitapta en uzun bölüm (s. 12–49), not üretilmedi
- s. 50–61 Doing european (Türkiye tartışması — ADE 279'un seçmeli olma gerekçesiyle
  ilgili olabilir)
