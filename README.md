## Okuma

- Her not dosyasi Markdown'dir; Obsidian, VS Code veya GitHub'da okunabilir.
- `[[...]]` baglantilari Obsidian icinde klasorler arasi gezinmeyi saglar.
- Kaynak PDF'ler ve ham metin bu depoya yuklenmez (boyut + telif).
