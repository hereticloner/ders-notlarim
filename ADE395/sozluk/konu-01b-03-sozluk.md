# Sözlük — 1.–3. hafta (ADE395)

A2+ ve üzeri kelimeler, bağlamlarıyla. A1 kelimeler girmez.

| Kelime/İfade | Anlam (bağlamıyla) |
| --- | --- |
| die Epoche, -n | dönem, edebiyat çağı (Weimarer Klassik als Epoche) |
| das Viergestirn | dört yıldız/dört büyük isim (Wieland, Goethe, Herder, Schiller) |
| die Blütezeit | çiçek/altın çağ (Alman edebiyatının) |
| die Schaffensperiode | yaratım dönemi (Goethe–Schiller 1794–1805) |
| die Ästhetische Allianz | estetik ittifak (Goethe–Schiller arkadaşlığının adı) |
| der Umsturz | devrim/alt üst olma (gewaltsamer Umsturz = şiddetli iktidar değişimi) |
| die Höherentwicklung | yükseliş gelişimi (toplumun evrimsel ilerleyişi) |
| der Ausgleich | uzlaşma, denge (karşıtlıkların harmonik uzlaşması) |
| das Streben nach | çaba, -e erişme isteği (Streben nach Harmonie) |
| die Vollkommenheit | tamamlanmışlık, kusursuzluk |
| die Humanität | hümanite, insanlık ülküsü |
| die Übereinstimmung | örtüşme, uyuşma (Inhalt und Form / Pflicht und Neigung) |
| die Pflicht, -en | görev (vs. die Neigung: eğilim, istek) |
| die schöne Seele | "güzel ruh": görev ve eğilimi örtüşen insan ideali |
| die Zeitlosigkeit | zamansızlık (klasik konuların çağ dışılığı) |
| erhaben | yüce (über allen Einfluss der Zeiten erhaben) |
| das Drama, -en | dram (Klasik'in ana türü) |
| tektonisches Drama | "tektonik dram": sıkı-simetrik kurgulu klasik dram |
| pyramidalen Aufbau | piramit yapı (dram kurgusu) |
| die drei Einheiten | üç birlik: Handlung/Zeit/Ort (olay, zaman, yer) |
| der Blankvers | blank verse (nüktesiz ölçü; Iphigenie'nin ölçüsü) |
| die Ballade, -n | balad (Geister-/numinose vs. Ideenballade) |
| der Zauberlehrling | "Sihirbaz Çırağı" (Goethe'nin numinos baladı) |
| die Bürgschaft | kefillik/arkadaşlık yemini (Schiller'in fikir baladı) |
| das Balladenjahr | "balad yılı" (1797) |
| die Natur | doğa (Goethe'de evrensel bağın modeli) |
| die Geschichte | tarih (Schiller'de ana başvuru alanı) |
| der Stil | üslup/stil (Goethe'nin sanat idealinin doruğu) |
| die einfache Nachahmung der Natur | doğanın basit taklidi (Goethe'nin üçlüsünden) |
| die Manier | biçem/kişisel üslup (aynı üçlünün ikinci kademesi) |
| der Bildung(s)roman | eğitim/biçimlenme romanı (Wilhelm Meister) |
| die ästhetische Erziehung | estetik eğitim (Schiller'in programı) |
| sinnlicher Trieb / Formtrieb | duyuşsal içgüdü / biçim içgüdüsü (Schiller'in ikiliği) |
| naiv / sentimentalisch | naif / duygusal-reflective (Schiller'in şiir türleri karşıtlığı) |
| der Satiriker / Elegiker / Idylle | satirik / elegik şair / idil (Schiller'in tür şeması) |
| die Trauerspiel, -e | trajedi (Empedokles, Antigone türü) |
| das Lustspiel / Komödie | komedya (Der gestiefelte Kater, Der zerbrochene Krug) |
| die Novelle, -n | novella (Mozart auf der Reise nach Prag) |
| die Übersetzung, -en | çeviri (Hölderlin'in Antigone'su) |
| unvollendet | tamamlanmamış (Empedokles'in üç taslağı) |
| der Entwurf, -"e | taslak (Empedokles'un üç Entwurf'u) |
| der Frankfurter Plan | "Frankfurt planı": Empedokles'un beş perdelik ilk planı (1797) |
| der Grund zum Empedokles | Hölderlin'in teorik yazısı (1799) |
| die Heimkehr der Götter | tanrıların dönüşü (Hölderlin'in beklenti ekseni) |
| die Retrospektive / Prospektive | geriye/ileriye bakış (Hölderlin'in iki zaman ekseni) |
| die Grenze, -n | sınır (romantik sınır/aşkınlık vurgusu) |
| das Unendliche | sonsuz (romantik amaç nesnesi) |
| das Wunderbare | acayip/mucizevi olan (romantik estetik kategori) |
| die Einbildungskraft | imgelem gücü |
| das Unbewusste | bilinçdışı |
| die Progrediente Poesie | "ilerleyen şiir" (F. Schlegel'in romantik programı) |
| progredierend | ilerleyen, sonsuza uzanan (şiir kendini sürekli yansıtır) |
| die Emphase, -n | vurgu/coşku (sınırın, sonsuzun vurgusu) |
| das Volkslied | halk şarkısı (romantik malzeme) |
| das Märchen | masal (romantik malzeme) |
| die Vorstufe | ön aşama (Mörike = Gerçekçiliğe Vorstufe) |
| der Bogen (des Semesters) | eğri/yay (dönem okuma listesinin izlediği eğri) |
